# Enshwick mods

The Enshrouded mods of the Enshwick project, each in its own folder and
released on its own. Built on [Enshwick](https://github.com/enshwick/enshwick).

| Mod | What it does |
| --- | --- |
| [Area Loot](area-loot/README.md) | Empty one enemy corpse and also get the loot of the enemies nearby. |
| [Better Altars](better-altars/README.md) | More Flame Altars per Flame level, and altar zones that touch grow together. |
| [Build Camera](build-camera/README.md) | Airborne Architect's building fly mode for every player, within the vanilla limits. |
| [Game Rates](game-rates/README.md) | Multipliers for building recipes, comfort, experience, workshops, loot and skill points. |
| [Optimizer](optimizer/README.md) | A dedicated server uses less CPU, on Windows and under Wine or Proton. |
| [Personal Safes](personal-safes/README.md) | Adds the Safe, a chest that only its owner and the players they allow can open. |
| [Shared Experience](shared-experience/README.md) | Every character catches up with the one that has the most experience. |
| [Survivors per Altar](survivors-per-altar/README.md) | A copy of each survivor at every Flame Altar, with a bed at its own altar. |

[`devtools/`](devtools/README.md) holds the developer mods, which never ship
to players.

Each folder keeps the history of the repository it came from. Licensed under
[MIT](LICENSE).
