# Enshwick mods

Mods for Enshrouded by the Enshwick team, each in its own folder and released
on its own. They run on [Enshwick](https://enshwick.com), the modding framework
and API for Enshrouded.

Each mod has a page on [enshwick.com](https://enshwick.com/#mods) that says
what it changes and links its archive.

| Mod | What it does |
| --- | --- |
| [Admin Tools](admin-tools/README.md) | Admins mute players in chat from the game. |
| [Area Loot](area-loot/README.md) | Loot one corpse, take the area’s loot. |
| [Better Altars](better-altars/README.md) | More Flame Altars, zones that grow together. |
| [Build Camera](build-camera/README.md) | The flying build camera for everyone. |
| [Game Rates](game-rates/README.md) | More from recipes, loot and experience. |
| [Optimizer](optimizer/README.md) | Less CPU for a dedicated server. |
| [Personal Safes](personal-safes/README.md) | A chest only its owner can open. |
| [Shared Experience](shared-experience/README.md) | All players stay on the same level. |
| [Survivors per Altar](survivors-per-altar/README.md) | Every base gets its own survivors. |

[`devtools/`](devtools/README.md) holds the developer mods, which never ship
to players.

Each folder keeps the history of the repository it came from. Licensed under
[MIT](LICENSE).
