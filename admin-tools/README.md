# Admin Tools

Admin Tools lets a server's administrators mute players in chat from the
game's interface.

Built on [Enshwick](https://github.com/enshwick/enshwick).

## In the game

An administrator opens the pause menu, **Mods**, **Actions** and **Muted in
chat**: a list of the players online with a switch each. A muted player's chat
lines reach no other player, and the muted player sees a notice that says so.
Administrators and the host are never muted, and a mute lasts in its world
across restarts until it is lifted. Other players never see the list, and the server checks
every switch again.

## Install

Download
`enshwick-admin-tools.zip` from its [newest release](https://github.com/enshwick/mods/releases?q=enshwick-admin-tools&expanded=true).
Extract it into the folder with `enshrouded_server.exe`. The mod needs the
Enshwick loader. Get
`enshwick.zip` from the [Enshwick release](https://github.com/enshwick/enshwick/releases)
that the mod's release notes name, and extract it into the same folder. Until 1.0 both are alphas, and anything may change from one alpha
to the next. Back up your saves before you update.

## Who needs it

Only the server. Players need Enshwick to see the list.
