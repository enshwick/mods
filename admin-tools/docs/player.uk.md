- Адміністратори бачать список гравців онлайн із перемикачем для кожного.
- Рядки гравця з вимкненим чатом не бачить жоден інший гравець.
- Гравець із вимкненим чатом бачить про це сповіщення.
- Адміністраторам і хосту чат не вимикається.

## Як вимкнути гравцю чат?

Ви маєте бути адміністратором сервера.

1. Відкрийте меню паузи, потім **Mods**.
2. Виберіть **Actions**, потім **Чат вимкнено**.
3. Увімкніть перемикач гравця, щоб вимкнути йому чат. Вимкніть перемикач, щоб
   гравець знову міг писати.

Відповідь під списком каже, що змінилося. Інші гравці цього списку не бачать.

## Скільки діє вимкнення чату?

Чат лишається вимкненим, доки адміністратор його не ввімкне. Це зберігається
після перезапуску сервера. Сервер тримає список у
`mod-data/enshwick/muted.txt`.

## Встановлення

Admin Tools є в окремому архіві, enshwick-admin-tools.zip. Йому потрібен
Enshwick з архіву enshwick.zip. Куди класти обидва архіви, показує
[посібник зі встановлення](https://enshwick.github.io/docs/uk/guides/install/).

## Гра з іншими

Admin Tools потрібен лише серверу. Гравцям потрібен Enshwick, щоб бачити
список.

## Проблеми

**Список не з'являється.** Перевірте, що ви адміністратор сервера.

**Щось інше йде не так.** Відкрийте issue в
[репозиторії модів](https://github.com/enshwick/mods/issues). Додайте файли з
теки `logs/enshwick/` у теці сервера.
