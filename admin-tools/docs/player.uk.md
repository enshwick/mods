- Адміністратори бачать, хто в мережі, виганяють, банять гравців або вимикають їм чат. Бан діє і після перезапуску.
- Список дозволених пускає лише обрані акаунти й адміністраторів, а кожен світ вирішує, хто може користуватися кожною дією.
- Гравці читають повідомлення дня, оголошення за розкладом і попередження про перезапуск.
- Адміністратори задають час і погоду, лікують і переносять гравців, зберігають світ і роблять його резервну копію, поки сервер працює.
- Програми RCON, як-от BattleMetrics, виконують усі команди на виділеному сервері, а журнали дій і чату зберігають, що сталося.

## Як скористатися дією?

Ви вводите дію як команду в чаті або у вікні консолі виділеного сервера.
Кожна команда починається з `/adl` або `/admin-tools`.

1. Відкрийте чат у грі.
2. Введіть `/adl help`, щоб побачити дії, які вам доступні.
3. Введіть команду, наприклад `/adl kick Bob`.

Відповідь бачите лише ви. У вікні консолі виділеного сервера вводьте той
самий рядок без `/`, наприклад `adl kick Bob`.

Консолі й програмам RCON доступні всі дії.

| Команда | Що робить |
| --- | --- |
| `/adl online` | Показує гравців у мережі, їхні id акаунтів, скільки кожен грає і кому вимкнено чат. |
| `/adl status` | Показує, скільки працює сервер, світ і версії Enshwick та модів. |
| `/adl motd` | Показує повідомлення дня. |
| `/adl kick <гравець>` | Прибирає гравця з гри. Він може зайти знову. |
| `/adl banned <гравець> on` | Банить гравця, який у мережі. |
| `/adl banned <гравець> off` | Знімає бан, також поки гравця немає. |
| `/adl allowed <гравець> on` або `off` | Додає гравця до списку дозволених або прибирає з нього. |
| `/adl muted <гравець> on` або `off` | Вимикає гравцю чат або вмикає знову. |
| `/adl heal <гравець>` | Повертає гравцю повне здоров'я. |
| `/adl stats <гравець> health`, `stamina` або `mana` `<значення>` | Встановлює гравцю здоров'я, витривалість або ману. Гра тримає значення в межах максимуму. |
| `/adl learn <гравець> <рецепт>` | Відкриває гравцю рецепт. Назви його назвою в грі, наприклад `Tool_Torch01`, у будь-якому регістрі; його GUID; або ідентифікатором вмісту мода. Номер дає будь-яке знання, яке гра зберігає для гравця. |
| `/adl god <гравець> on` або `off` | Гравця в режимі бога ніщо не ранить. Режим закінчується, коли гравець виходить або світ зупиняється. |
| `/adl give <гравець> <кількість> <предмет>` | Дає гравцю нові предмети, до одного стосу. Назви предмет його назвою в грі, наприклад `Tool_Glider_T1`, у будь-якому регістрі; його GUID; ідентифікатором вмісту мода; або номером. На невідому назву мод показує схожі. |
| `/adl clear <гравець>` | Знищує все, що має гравець, разом зі спорядженням і панеллю дій. |
| `/adl copy <гравець> <гравець>` | Дає другому гравцю нові предмети з кожного стосу першого. Предмети нові, без зносу й рівня. Те, що не влізло, не дається. |
| `/adl goto <гравець>` | Переносить вас до гравця. |
| `/adl bring <гравець>` | Переносить гравця до вас. |
| `/adl send <гравець> <гравець>` | Переносить першого гравця до другого. |
| `/adl place <гравець> <x> <y> <z>` | Переносить гравця в точку в метрах, на вільне місце поруч із нею. |
| `/adl time <година>` | Задає час доби, наприклад `6.5` для 06:30. |
| `/adl weather clear` | Запускає погоду: `clear`, `rain`, `blizzard` або `any` на вибір гри. |
| `/adl restart <хвилини>` | Попереджає всіх гравців про перезапуск і зберігає світ, коли час вийде. `0` зупиняє попередження. Лише на виділеному сервері. |
| `/adl save` | Зберігає світ зараз. |
| `/adl backup` | Копіює світ у теку резервних копій, поки сервер працює. |
| `/adl world` | Показує світ, його останнє збереження і налаштування гри. |
| `/adl audit <рядки>` | Показує останні рядки журналу дій, до 50. |
| `/adl chat <рядки>` | Показує останні рядки журналу чату, до 50. |

Адміністраторів і хоста не можна вигнати, забанити чи вимкнути їм чат.
`goto` і `bring` потребують персонажа, тому консоль ними не користується.

## Як не пускати чужих?

1. Додайте кожного гравця, якому довіряєте, до списку дозволених командою
   `/adl allowed <гравець> on`, поки він у мережі.
2. Відкрийте екран модів, виберіть Admin Tools і увімкніть **Список
   дозволених** у налаштуваннях сервера.

Відтоді акаунт не зі списку виганяється, щойно заходить. Адміністратори
заходять завжди. Щоб додати гравця, вимкніть список, додайте гравця, поки він
у мережі, і знову увімкніть список.

## Як вирішити, хто може користуватися кожною дією?

Кожна дія має правило в налаштуваннях світу, у розділі **Хто може
користуватися кожною дією**. Правило — одне з цих:

- `everyone`
- `nobody`. Тоді дією може користуватися лише консоль сервера.
- Дозвіл групи гравця з `enshrouded_server.json`: `CanKickBan` для
  адміністраторів, `CanAccessInventories`, `CanEditBase`, `CanEditWorld`,
  `CanExtendBase` або `CanReceiveExp`.

Типово `online`, `status` і `motd` доступні всім, а решта дій —
адміністраторам. Гравець бачить лише дії, які дозволяє його правило. Зміна
діє протягом двох секунд.

## Як попередити гравців перед перезапуском?

Введіть `/adl restart 10`. Кожен гравець прочитає, що сервер перезапуститься
за 10 хвилин. Попередження з'явиться знову, коли залишиться 5, 2 і 1 хвилина,
і ще раз, коли час вийде.

Коли час вийде, Admin Tools зберігає світ. Сервер він не зупиняє: його
зупиняє панель або скрипт вашого хостингу, тож налаштуйте попередження так,
щоб воно закінчувалося, коли панель перезапускає сервер.

Введіть `/adl restart 0`, щоб скасувати перезапуск. У грі, яку хостить
гравець, попередження про перезапуск немає.

## Як під'єднати програму RCON?

На виділеному сервері віддалена консоль увімкнена з першого запуску. Вона
слухає лише на комп'ютері сервера. Вона говорить Source RCON, який розуміють
BattleMetrics, rcon-cli і mcrcon.

1. Відкрийте `rcon-password.txt` у `<save>-mod-data/enshwick.admin-tools/`
   поруч зі збереженням світу. Admin Tools записує туди випадковий пароль під
   час першого запуску, а журнал сервера називає цей файл.
2. У програмі на комп'ютері сервера введіть `127.0.0.1`, порт `25575` і цей
   пароль.
3. Надішліть команду без `/`, наприклад `adl online`. Надішліть `help`, щоб
   побачити команди всіх модів.

Щоб задати пароль самому, заповніть **Пароль віддаленої консолі** в
налаштуваннях світу. Щоб вимкнути консоль, поставте **Віддалена консоль** на
off.

RCON не шифрується: пароль і команди йдуть мережею відкритим текстом.
Щоб під'єднатися з іншого комп'ютера, скористайтеся SSH-тунелем чи VPN. Або
поставте **Адреса віддаленої консолі** на `0.0.0.0` і відкрийте порт лише
для комп'ютерів, яким довіряєте.

Після трьох хибних паролів з однієї адреси ця адреса чекає хвилину.
Програму, яка не ввійшла за 10 секунд, від'єднано.

## Як зробити резервну копію світу?

Введіть `/adl backup`. Admin Tools тримає збереження світу й копіює
збереження з налаштуваннями й даними модів цього світу в теку, названу за
часом UTC. Потім він знову відпускає збереження, також коли копіювання не
вдалося.

Гравці грають далі. Коли копія готова, ви прочитаєте, де вона.

Копії йдуть у `backups/` у `<save>-mod-data/enshwick.admin-tools/`. Якщо
задати **Тека резервних копій**, вони йдуть у теку з назвою збереження в ній.

Admin Tools тримає 10 найновіших або стільки, скільки каже **Скільки копій зберігати**, і видаляє старіші. Щоб
відновити копію, зупиніть сервер і скопіюйте файли з теки копії назад поруч
зі збереженням світу.

## Де журнал дій і журнал чату?

Обидва лежать у `<save>-mod-data/enshwick.admin-tools/` поруч зі
збереженням світу.

- `audit.log` має рядок на кожну зміну адміністратора: час за UTC, хто діяв,
  звідки, дію, її значення і результат. Читання, як-от `online`, не
  записуються. Входи через RCON записуються теж.
- `chat.log` має рядок на кожен рядок чату: час за UTC, ім'я гравця й id
  акаунта, вид рядка і його текст.

Коли журнал чату увімкнено, усе, що гравці пишуть у чат, зберігається на
сервері. Він увімкнений на виділеному сервері й вимкнений у грі, яку хостить
гравець, якщо налаштування світу **Журнал чату** не каже інакше. Після 1 МБ
журнал переходить в `audit.1.log` або `chat.1.log` і починається знову.

## Встановлення

Admin Tools постачається в окремому архіві enshwick-admin-tools.zip. Йому
потрібен Enshwick з архіву enshwick.zip.
[Посібник зі встановлення](https://enshwick.com/uk/guides/install/) показує,
куди покласти обидва архіви.

## Гра з іншими

Admin Tools потрібен лише серверу. Гравці без Enshwick можуть заходити й
користуватися командами в чаті.

## Проблеми

**`/adl` потрапляє в чат як звичайний рядок.** Перевірте, що Admin Tools
лежить у теці `mods/` сервера. Якщо так, журнал сервера пояснює, чому Admin
Tools вимкнено.

**Відповідь каже, що гравця з таким ім'ям немає.** Перевірте, що гравець у
мережі. Пишіть ім'я так, як його показує гра.

**Гравця виганяє, щойно він заходить.** Список дозволених увімкнено, а гравця
в ньому немає, або гравця забанено. Зніміть бан командою
`/adl banned <гравець> off`.

**Програма RCON не під'єднується.** Перевірте, що порт відкритий у
брандмауері і що журнал сервера каже, що віддалена консоль слухає. Якщо порт
зайняла інша програма, задайте інший у **Порт віддаленої консолі**.

**Щось інше пішло не так.** Відкрийте issue в
[репозиторії модів](https://github.com/enshwick/mods/issues). Додайте файли з
теки `logs/` у теці сервера.
