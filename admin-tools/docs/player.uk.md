- **Віддалена консоль:** будь-яка команда з програми RCON, без входу в гру.
- **Гравці й доступ:** хто в мережі, вигнання, бани з причинами, вимкнення
  чату, список дозволених. Забанити можна й гравця не в мережі.
- **Чат і оголошення:** повідомлення дня, оголошення за розкладом, рядок
  усім зараз, попередження про перезапуск.
- **Світ і сервер:** час доби, погода, збереження, резервні копії під час
  роботи сервера, налаштування гри для світу, журнали дій, чату й
  будівництва.
- **Персонажі й предмети:** лікування, здоров'я, витривалість і мана,
  рецепти, режим бога, предмети чи скриня з предметами, очищення й
  копіювання інвентарю.

## Як під'єднати програму RCON?

На виділеному сервері віддалена консоль увімкнена з першого запуску. Вона
говорить Source RCON — протоколом таких програм, як rcon-cli, mcrcon і
BattleMetrics.

| | |
| --- | --- |
| Адреса | `127.0.0.1`, комп'ютер сервера |
| Порт | `25575` |
| Пароль | у `rcon-password.txt` у `<save>-mod-data/enshwick.admin-tools/` поруч зі збереженням світу |
| Типово увімкнена | на виділеному сервері; у грі, яку проводить гравець, вимкнена |

1. Відкрийте `rcon-password.txt`. Admin Tools записує туди випадковий пароль
   під час першого запуску, а журнал сервера називає цей файл.
2. У програмі введіть адресу, порт і цей пароль.
3. Надішліть команду без `/`, наприклад `adm online`. Надішліть `help`, щоб
   побачити команди всіх модів.

RCON не шифрується: пароль і команди йдуть мережею відкритим текстом. Щоб
під'єднатися з іншого комп'ютера, скористайтеся SSH-тунелем чи VPN. Або
поставте **Адреса віддаленої консолі** на `0.0.0.0` і відкрийте порт лише
для комп'ютерів, яким довіряєте.

Щоб задати пароль самому, заповніть **Пароль віддаленої консолі** в
налаштуваннях світу. Щоб вимкнути консоль, поставте **Віддалена консоль** на
off. Після трьох хибних паролів з однієї адреси ця адреса чекає хвилину.

## Які є команди?

Кожна дія — це команда в чаті, у вікні консолі виділеного сервера і в
програмі RCON. Вона починається з `/adm` або `/admin-tools`. У консолі й
програмі RCON пишіть її без `/`.

`/adm help` показує дії, які вам доступні, а `/adm help <дія>` пояснює одну.
Аргумент у квадратних дужках можна пропустити.

| Команда | Що робить | Типово |
| --- | --- | --- |
| `/adm online` | Показує гравців у мережі, їхні id акаунтів і час у грі. | Усі |
| `/adm kick <гравець>` | Прибирає гравця з гри. Він може зайти знову. | Адміни |
| `/adm muted <гравець> on` або `off` | Вимикає гравцю чат або вмикає знову. | Адміни |
| `/adm ban <гравець> <причина>` | Банить гравця, у мережі чи ні, з причиною. | Адміни |
| `/adm bans` | Показує 50 найновіших банів з причинами. | Адміни |
| `/adm banned <гравець> on` або `off` | Банить гравця або знімає бан. | Адміни |
| `/adm allowed <гравець> on` або `off` | Додає гравця до списку дозволених або прибирає з нього. | Адміни |
| `/adm account <id> ban`, `unban`, `allow` або `disallow` | Змінює акаунт за його id, також такий, що ніколи не заходив. | Адміни |
| `/adm mark <гравець>` | Переносить гравця до позначки на вашій мапі. | Адміни |
| `/adm goto <гравець>` | Переносить вас до гравця. | Адміни |
| `/adm bring <гравець>` | Переносить гравця до вас. | Адміни |
| `/adm send <гравець> <гравець>` | Переносить першого гравця до другого. | Адміни |
| `/adm place <гравець> <x> <y> <z>` | Переносить гравця в точку в метрах. | Адміни |
| `/adm heal <гравець>` | Повертає гравцю повне здоров'я. | Адміни |
| `/adm stats <гравець> health`, `stamina` або `mana` `<значення>` | Встановлює гравцю здоров'я, витривалість або ману. | Адміни |
| `/adm learn <гравець> <рецепт>` | Відкриває гравцю рецепт. | Адміни |
| `/adm god <гравець> on` або `off` | Гравця ніщо не ранить, доки він не вийде. | Адміни |
| `/adm give <гравець> <предмет> [кількість]` | Дає гравцю предмети, один, якщо кількість не вказано. | Адміни |
| `/adm clear <гравець>` | Знищує все, що гравець несе й носить. | Адміни |
| `/adm copy <гравець> <гравець>` | Дає другому гравцю нові предмети з усього, що несе перший. | Адміни |
| `/adm chest <гравець> <предмет> [кількість]` | Ставить скриню з предметами біля гравця. | Адміни |
| `/adm chestat <x> <y> <z> <предмет> [кількість]` | Ставить скриню з предметами в точці. | Адміни |

| `/adm say <текст>` | Показує рядок усім гравцям зараз. | Адміни |
| `/adm restart <хвилини>` | Попереджає всіх про перезапуск і зберігає світ, коли час вийде. `0` зупиняє. Лише на виділеному сервері. | Адміни |
| `/adm status` | Показує, скільки працює сервер, світ і версії модів. | Усі |
| `/adm time <час>` | Задає час доби, наприклад `18:30` або `6.5` для 06:30. | Адміни |
| `/adm weather <погода>` | Запускає `clear`, `rain`, `blizzard` або `any` на вибір гри. | Адміни |
| `/adm save` | Зберігає світ зараз. | Адміни |
| `/adm world` | Показує світ, його останнє збереження і налаштування гри. | Адміни |
| `/adm backup` | Копіює світ у теку резервних копій, поки сервер працює. | Адміни |
| `/adm audit <рядки>` | Показує останні рядки журналу дій, до 50. | Адміни |
| `/adm chat <рядки>` | Показує останні рядки журналу чату, до 50. | Адміни |
| `/adm who <метри>` | Показує 10 останніх змін будівель і ландшафту біля вас, до 200 метрів. | Адміни |
| `/adm panel` | Відкриває вікно Admin Tools. | Адміни |
| `/adm open <розділ>` | Відкриває один розділ вікна: `players`, `accounts`, `server` або `builds`. | Адміни |
| `/adm player <гравець>` | Відкриває вікно одного гравця. | Адміни |

Адміни — гравці, чия група дає `CanKickBan`. Адмінів і хоста не можна
вигнати, забанити чи вимкнути їм чат. `goto`, `bring`, `mark` і `who`
потребують персонажа, тому консоль ними не користується.

Гравця не в мережі називайте так, як він востаннє заходив у цей світ. Admin
Tools пам'ятає останні 256 акаунтів, які пробували зайти. Ще він пам'ятає
кожен акаунт зі списку банів чи списку дозволених.

## Як назвати предмет чи рецепт?

- Налагоджувальною назвою, наприклад `Tool_Glider_T1`, у будь-якому регістрі.
- Його GUID або ідентифікатором вмісту мода, наприклад `you.lockers:locker`.
- У грі, яку проводить гравець, також назвою, яку показує гра, наприклад
  `Параплан`, будь-якою мовою гри. На виділеному сервері цих назв немає.
- Предмет — номером, а будь-яке знання для `learn` — його номером.

На невідому назву мод показує схожі. `give`, `chest` і `chestat` дають
стільки стосів, скільки треба, і ви бачите, скільки не вмістилося.

Предмети з `copy` нові, без зносу й рівня, а слоти вигляду й валюти не
копіюються. Скриня поза базами не зберігається.

## Як відкрити вікно Admin Tools?

Натисніть Shift+F9 у грі або введіть `/adm panel`. У вікні чотири розділи, і
кожен показує лише дії, які вам доступні:

| Розділ | Що в ньому |
| --- | --- |
| Гравці | Гравці в мережі. **Дії** відкриває вікно одного гравця: перенесення, модерація, здоров'я, предмети й рецепти. |
| Бани й список дозволених | Бани з причинами, кожен з кнопкою, що знімає бан, і список дозволених. |
| Сервер | Повідомлення дня, попередження про перезапуск, час доби, погода, збереження й резервні копії. |
| Журнал будівництва | Зміни біля вас, кожна з кнопкою, що переносить вас туди. |

Щоб змінити клавішу, відкрийте екран модів, виберіть Admin Tools і змініть її
серед клавіш мода.

## Як не пускати чужих?

1. Додайте кожного гравця, якому довіряєте, до списку дозволених командою
   `/adm allowed <гравець> on` або ввімкніть його в розділі вікна **Бани й
   список дозволених**.
2. Відкрийте екран модів, виберіть Admin Tools і увімкніть **Список
   дозволених** у налаштуваннях сервера.

Відтоді акаунт не зі списку виганяється, щойно заходить. Адміни
заходять завжди. Гравця, якого так вигнало, Admin Tools пам'ятає, тож його
можна потім дозволити за ім'ям.

Щоб дозволити акаунт, який ніколи не заходив, попросіть у гравця id акаунта й
введіть `/adm account <id> allow`.

## Як вирішити, хто може користуватися кожною дією?

Кожна дія має правило в налаштуваннях світу, у розділі **Хто може
користуватися кожною дією**. Таблиця команд показує типове правило кожної.

| Правило | Хто може користуватися дією |
| --- | --- |
| `everyone` | Кожен гравець. |
| `nobody` | Жоден гравець. Консоль сервера й програми RCON можуть і далі. |
| `CanKickBan` | Адміни. |
| `CanAccessInventories`, `CanEditBase`, `CanEditWorld`, `CanExtendBase` або `CanReceiveExp` | Гравці, чия група в `enshrouded_server.json` дає цей дозвіл. |

Гравець бачить лише дії, які дозволяє його правило. Зміна діє протягом двох
секунд.

## Як попередити гравців перед перезапуском?

Введіть `/adm restart 10`. Кожен гравець прочитає, що сервер перезапуститься
за 10 хвилин. Попередження з'явиться знову, коли залишиться 5, 2 і 1 хвилина,
і ще раз, коли час вийде.

Коли час вийде, Admin Tools зберігає світ. Сервер він не зупиняє: його
зупиняє панель або скрипт вашого хостингу, тож налаштуйте попередження так,
щоб воно закінчувалося, коли панель перезапускає сервер.

Введіть `/adm restart 0`, щоб скасувати перезапуск. У грі, яку хостить
гравець, попередження про перезапуск немає.

## Як зробити резервну копію світу?

Введіть `/adm backup`. Admin Tools тримає збереження світу й копіює
збереження з налаштуваннями й даними модів цього світу в теку, названу за
часом UTC. Потім він знову відпускає збереження, також коли копіювання не
вдалося.

Гравці грають далі. Коли копія готова, ви прочитаєте, де вона.

Копії йдуть у `backups/` у `<save>-mod-data/enshwick.admin-tools/`. Якщо
задати **Тека резервних копій**, вони йдуть у теку з назвою збереження в ній.

Admin Tools тримає 10 найновіших або стільки, скільки каже **Скільки копій зберігати**, і видаляє старіші. Щоб
відновити копію, зупиніть сервер і скопіюйте файли з теки копії назад поруч
зі збереженням світу.

## Як побачити, хто збудував чи зламав щось?

Спершу увімкніть **Журнал будівництва** в налаштуваннях світу. Відтоді Admin
Tools записує кожну поставлену, підняту чи зруйновану будівлю. Ще він записує
кожне місце, де поставили чи прибрали будівельні блоки або змінили ландшафт.

Кожен рядок має, хто це зробив, час і точку.

Зміни ландшафту й будівельних блоків називають найближчого гравця в межах 16
метрів, бо гра не каже, хто їх зробив.

1. Підійдіть до місця.
2. Відкрийте вікно Admin Tools і його розділ **Журнал будівництва** або
   введіть `/adm who 30`, щоб побачити зміни в межах 30 метрів.
3. Натисніть **Туди** біля зміни, щоб стати там, де вона сталася.

Журнал не має нічого з часу до того, як ви його ввімкнули.

## Де журнали?

Журнали лежать у `<save>-mod-data/enshwick.admin-tools/` поруч зі
збереженням світу. Кожен рядок починається з часу за UTC.

| Файл | Що в ньому | Типово увімкнений |
| --- | --- | --- |
| `audit.log` | Кожен запуск дії, яка щось змінює, виконаний чи відхилений: хто, звідки, дія, її значення й відповідь. Також входи через RCON і зміна, яку гра зробила лише частково після відповіді, як-от видача предметів. Читання, як-от `online`, не записуються. | На виділеному сервері |
| `chat.log` | Кожен рядок чату: ім'я гравця й id акаунта, вид рядка і його текст. | На виділеному сервері |
| `builds.log` | Кожна поставлена чи прибрана будівля й кожне місце зміни блоків чи ландшафту, з тим, хто це зробив. | Ні |

У грі, яку проводить гравець, журналів немає, доки їх не ввімкнуть
налаштування світу. Коли журнал чату увімкнено, усе, що гравці пишуть у чат,
зберігається на сервері. Після 1 МБ журнал переходить в `audit.1.log`,
`chat.1.log` або `builds.1.log` і починається знову.

## Встановлення

Admin Tools постачається в окремому архіві enshwick-admin-tools.zip. Йому
потрібен Enshwick з архіву enshwick.zip.
[Посібник зі встановлення](https://enshwick.com/uk/guides/install/) показує,
куди покласти обидва архіви.

## Гра з іншими

Admin Tools потрібен лише серверу. Гравці без Enshwick можуть заходити й
користуватися командами в чаті.

## Проблеми

**`/adm` потрапляє в чат як звичайний рядок.** Перевірте, що Admin Tools
лежить у теці `mods/` сервера. Якщо так, журнал сервера пояснює, чому Admin
Tools вимкнено.

**Відповідь каже, що гравця з таким ім'ям немає.** Пишіть ім'я так, як його
показує гра. Гравця не в мережі Admin Tools знає, лише якщо він пробував
зайти в цей світ; для будь-якого іншого акаунта введіть `/adm account <id>`.

**Гравця виганяє, щойно він заходить.** Список дозволених увімкнено, а гравця
в ньому немає, або гравця забанено. Зніміть бан командою
`/adm banned <гравець> off`.

**Програма RCON не під'єднується.** Перевірте, що порт відкритий у
брандмауері і що журнал сервера каже, що віддалена консоль слухає. Якщо порт
зайняла інша програма, задайте інший у **Порт віддаленої консолі**.

**Щось інше пішло не так.** Відкрийте issue в
[репозиторії модів](https://github.com/enshwick/mods/issues). Додайте файли з
теки `logs/` у теці сервера.
