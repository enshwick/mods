- Адміністратори вимикають і вмикають гравцям чат.
- Рядки гравця з вимкненим чатом не бачить жоден інший гравець.
- Гравець із вимкненим чатом бачить про це сповіщення.
- Адміністраторам і хосту чат не вимикається.

## Як вимкнути гравцю чат?

Ви вводите рядок у вікні консолі виділеного сервера. Сервер виконує його як
адміністратор.

1. Відкрийте вікно консолі виділеного сервера.
2. Введіть `enshwick.admin-tools muted <гравець> on`, щоб вимкнути гравцю чат.
   Пишіть ім'я гравця так, як його показує гра.
3. Введіть `enshwick.admin-tools muted <гравець> off`, щоб гравець знову міг
   писати.

Консоль відповідає наступним рядком і каже, що змінилося. Гравець має бути в
мережі. Інші гравці цих рядків не бачать.

## Чи можна вимкнути гравцю чат у самій грі?

Ні. Admin Tools не має вікна в грі. Гра, яку хостить гравець, не має вікна
консолі, тож її гравцям чат вимкнути не можна.

## Скільки діє вимкнення чату?

Чат лишається вимкненим у цьому світі, доки адміністратор його не ввімкне. Це
зберігається після перезапуску сервера. Кожен світ має свій список,
`<save>-mod-data/enshwick/muted.txt` поруч зі збереженням.

## Встановлення

Admin Tools є в окремому архіві, enshwick-admin-tools.zip. Йому потрібен
Enshwick з архіву enshwick.zip. Куди класти обидва архіви, показує
[посібник зі встановлення](https://enshwick.com/uk/guides/install/).

## Гра з іншими

Admin Tools потрібен лише серверу.

## Проблеми

**Консоль каже, що мод enshwick.admin-tools не завантажено.** Перевірте, що
рядок починається з `enshwick.admin-tools` і що Admin Tools лежить у теці
`mods/` сервера. Якщо все так, журнал сервера каже, чому Admin Tools вимкнено.

**Консоль не знаходить гравця з таким ім'ям.** Перевірте, що гравець у мережі.
Пишіть ім'я так, як його показує гра.

**Щось інше йде не так.** Відкрийте issue в
[репозиторії модів](https://github.com/enshwick/mods/issues). Додайте файли з
теки `logs/` у теці сервера.
