# Area loot

Empty one enemy corpse and the loot of the others around it comes along. An Enshrouded mod for the
[Enshwick](https://github.com/enshwick/enshwick) loader.

Its settings are `mod-configs/area-loot.toml`, written on first start; its
log is `logs/enshwick/mods/area-loot.log`. Development builds are on the
[`dev` prerelease](https://github.com/enshwick/mod-area-loot/releases/tag/dev).
