# Flame altar count

How many Flame Altars each Flame level allows, from a table in the settings. An Enshrouded mod for the
[Enshwick](https://github.com/enshwick/enshwick) loader.

Its settings are `mod-configs/flame-altar-count.toml`, written on first start; its
log is `logs/enshwick/mods/flame-altar-count.log`. Development builds are on the
[`dev` prerelease](https://github.com/enshwick/mod-flame-altar-count/releases/tag/dev).
