# Build camera

Airborne Architect's building fly mode for every player, within the vanilla limits. An Enshrouded mod for the
[Enshwick](https://github.com/enshwick/enshwick) loader.

Its settings are `mod-configs/build-camera.toml`, written on first start; its
log is `logs/enshwick/mods/build-camera.log`. Development builds are on the
[`dev` prerelease](https://github.com/enshwick/mod-build-camera/releases/tag/dev).
