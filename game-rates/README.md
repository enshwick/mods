# Building materials

Building blocks, roofs, overgrowth, decor and furniture: twice the output of the vanilla recipes for the same cost. An Enshrouded mod for the
[Enshwick](https://github.com/enshwick/enshwick) loader.

Its settings are `mod-configs/building-materials.toml`, written on first start; its
log is `logs/enshwick/mods/building-materials.log`. Development builds are on the
[`dev` prerelease](https://github.com/enshwick/mod-building-materials/releases/tag/dev).
