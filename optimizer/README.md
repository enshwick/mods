# Optimizer

Less server CPU on Windows and under Wine or Proton: exact short waits, task workers within a container's CPU limit, measurements and an environment report. An Enshrouded mod for the
[Enshwick](https://github.com/enshwick/enshwick) loader.

Its settings are `mod-configs/optimizer.toml`, written on first start; its
log is `logs/enshwick/mods/optimizer.log`. Development builds are on the
[`dev` prerelease](https://github.com/enshwick/mod-optimizer/releases/tag/dev).
