# Safes

The Safe: a craftable chest only the player who placed it can open. An Enshrouded mod for the
[Enshwick](https://github.com/enshwick/enshwick) loader.

Its settings are `mod-configs/safes.toml`, written on first start; its
log is `logs/enshwick/mods/safes.log`. Development builds are on the
[`dev` prerelease](https://github.com/enshwick/mod-safes/releases/tag/dev).
