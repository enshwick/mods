# Shared experience

Every character on a server keeps up with the one furthest ahead in experience. An Enshrouded mod for the
[Enshwick](https://github.com/enshwick/enshwick) loader.

Its settings are `mod-configs/shared-experience.toml`, written on first start; its
log is `logs/enshwick/mods/shared-experience.log`. Development builds are on the
[`dev` prerelease](https://github.com/enshwick/mod-shared-experience/releases/tag/dev).
