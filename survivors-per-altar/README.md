# Survivors per altar

A copy of each survivor at every Flame Altar, each with the bed of its own altar. An Enshrouded mod for the
[Enshwick](https://github.com/enshwick/enshwick) loader.

Its settings are `mod-configs/survivors-per-altar.toml`, written on first start; its
log is `logs/enshwick/mods/survivors-per-altar.log`. Development builds are on the
[`dev` prerelease](https://github.com/enshwick/mod-survivors-per-altar/releases/tag/dev).
